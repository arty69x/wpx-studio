# ARTYVERSE X AI ASSISTANT — Design OS 3.0

Clean rebuild from the ARTYVERSE X Master Blueprint. React + TypeScript + Tailwind CSS + Framer Motion + Lucide + Web Audio API. No Lovable runtime or paid backend.

## Run

npm install
npm run dev
npm run build

## Safety and scope

This is a functional **frontend demo**, not a connected AI service. Chat messages are saved in browser localStorage. Microphone permission opens a local stream only and is released on stop/unmount. Audio cues are opt-in. Focus mode and reduced-motion fallback are available. No keys or credentials are embedded.

## Routes

Single-page navigation: Home, Chat, Interview, Design OS. Next stage: production API proxy, secure authentication, persistent server-side conversations, interview transcription, billing, test coverage, and CI deployment.
